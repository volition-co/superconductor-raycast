# Superconductor Changelog

## [Initial Release] - {PR_MERGE_DATE}

- Add Create Multiple Tickets to keep creating tickets in one project.
- Write a ticket in the launcher, then search or navigate projects with the arrow keys.
- Star projects locally to keep frequent destinations at the top.
- Generate ticket titles automatically from the description.
- Start the account's default implementation, or create a ticket without launching an agent.
- Open the new implementation automatically, with the ticket as a fallback, and dismiss Raycast.
- Show whether the agent started and prompt you to check the project if a connection problem leaves ticket creation unconfirmed.
